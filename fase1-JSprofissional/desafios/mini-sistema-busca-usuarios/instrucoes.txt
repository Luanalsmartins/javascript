----- DESAFIO - MINI SISTEMA DE BUSCA DE USUÁRIOS -----

Vamos usar essa API: https://jsonplaceholder.typicode.com/users

Para: 
1️ Buscar os usuários da API - ok
2️ Mostrar TODOS os nomes na tela - ok
3️ Criar um input de busca - ok
4️ Conforme a pessoa digitar, filtrar os nomes em tempo real - ok
5️ Ordenar os resultados em ordem alfabética - ok

----------------- Regras do desafio -----------------

Quando a página carregar:
- Buscar usuários - ok
- Salvar em uma variável - ok
- Mostrar todos inicialmente - ok 

Quando digitar no input:
- Filtrar nomes que incluam o texto digitado
- Ignorar maiúscula/minúscula
- Ordenar alfabeticamente
- Atualizar a lista na tela

Conceitos que você vai usar: 
- fetch
- filter
- map
- sort
- toLowerCase
- addEventListener
- manipulação de DOM
